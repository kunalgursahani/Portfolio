# Kunal Gursahani — Portfolio

Static site, no build step needed.

## Edit your links
Open `index.html`, find the `<!-- >>> EDIT ME -->` comment inside the
`#connect` section, and replace each `href="#"` with your real profile URL
(email, LinkedIn, GitHub, SAP Community, blog, X/Twitter). You can also
update the `connect-value` text next to each icon.

## Deploy to Vercel
1. Push this folder to a GitHub repo (or drag-and-drop it in the Vercel dashboard).
2. In Vercel: New Project → Import → select the repo/folder.
3. Framework preset: "Other" (it's plain HTML/CSS/JS — no build command needed).
4. Deploy.

That's it — no `npm install`, no build step.
